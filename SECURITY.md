# Security Policy

## Scope

This repository is a demo-only learning application. It does not implement Stockity authentication, market-data scraping, or broker order submission. Real and unknown account modes must always fail closed.

## Reporting

Please report vulnerabilities privately through GitHub's **Report a vulnerability** feature for this repository. Do not include passwords, OTPs, cookies, access tokens, or financial account identifiers in issues or logs.

## Supported versions

Only the latest repository version is currently supported.
